# reference/

`paper2_code/`: the 15 scripts from the SVLM paper's Zenodo record (10.5281/zenodo.22812951), unpacked here so the
summariser (`html_truncation_github.py`, function `reduce_html`) and the sampling logic (`select_sample_gtihub.py`)
can be read and ported. Do not run these scripts as-is: all data paths in them are blanked.
The JCP paper's code is at https://github.com/sbaresearch/benchmarking-SLMs (tag-based truncation used for state S3).
