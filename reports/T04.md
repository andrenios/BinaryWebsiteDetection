# T04 — Go/no-go pilot (training split, 300 balanced sites)

Session 1, 2026-10-04. **Not run on the training split** — the data is not on this machine.

## Script status

`scripts/t04_pilot.py` is written and was exercised on 100 bootstrap PhreshPhish
sites (pseudo training split): bank_v1 + `q_direct` in one request per site,
per-question AUROC and noul distribution, Spearman correlation matrix with a
heatmap, cost and latency summary. Site selection is label-balanced after a
seeded shuffle (decisions D12). Outputs: `results/t04_<dataset>_S1_{table,per_question,correlation,summary}.csv`,
`figures/t04_<dataset>_S1_corr.{pdf,png}`.

Command when the data arrives: `python scripts/t04_pilot.py --dataset putra --split train --n 300`
(≈ 300 requests, ≈ 0.02 USD, < 1 min at 4 workers).

## What the bootstrap exercise showed (debugging only, not a result)

The request shape works (100/100 ok, 1,830 input tokens mean, p50 ≈ 280 ms).
On PhreshPhish pages the URL-shaped questions (`q_ip_or_freehost`,
`q_suspicious_url_shape`) and `q_language_brand_mismatch` ranked above
`q_direct`; the deterministic-field questions (`q_collects_credentials`,
`q_form_offsite`, `q_obfuscated_scripts`) were at or below chance. Several
questions are strongly correlated. Whether this holds on Putra is exactly what
the pilot will show.

Go/no-go decision remains Andreas's, on this report once it has numbers.
